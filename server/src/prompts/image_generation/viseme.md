You are a master digital character artist specializing in micro-details and game assets.
Generate a single **SPRITESHEET IMAGE** containing a **3x2 GRID** of different mouth shapes for the following character.

- **Name**: {{name}}
- **Traits**: {{traits}}
- **Description**: {{description}}

### TARGET OUTPUT (3x2 GRID)
You MUST generate exactly ONE image divided perfectly into a grid with 3 columns and 2 rows.
Each cell must contain a close-up of the character's mouth with a different expression/shape:
- **Row 1, Col 1**: High-open "A" sound (exaggerated open mouth).
- **Row 1, Col 2**: Rounded "O" sound.
- **Row 1, Col 3**: Forward "U" sound (puckered lips).
- **Row 2, Col 1**: Wide "I" sound (showing teeth).
- **Row 2, Col 2**: Closed "S" or "M" sound (neutral or slightly smiling).
- **Row 2, Col 3**: Neutral/Empty background.

### STYLE & LIGHTING
- **Style**: {{style}}
- **Match Reference**: STRICTLY match the skin tone, texture, lighting, and facial features of the character reference image. Only the mouth, teeth, and interior of the mouth should be visible and must match the character reference image. Do not include any other facial features.

- **Focus**: Macro close-up on the lips, teeth, and interior. High resolution detail. Ensure all 6 mouths are the exactly same size and perfectly aligned in the 3x2 grid.
